User Guide
==========

A comprehensive, example-driven **standalone HTML user guide** is maintained in
the repository at `docs/user_guide.html <user_guide.html>`_. It is fully
self-contained (no external dependencies) and readable offline — open it
directly in a browser. It covers the quickstart, every data format and SQL
dialect, type inference, the full CLI reference, nested/child tables, ORM
generation, the Python API, security, and troubleshooting.
